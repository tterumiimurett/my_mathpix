记录口径：一次 Snippet 从首次选择开始计数；为同一内容重新选择算需要重截。High-Quality Retry 复用原 Snippet，不算新的 Screen Capture；fast 耗时从 Recognition Attempt 开始到结果可用，以 App 的已记录耗时为准。成功率为无需重截数 / Snippet 尝试数；fast 速度比例为 ≤5 秒数 / fast 尝试数，没有尝试时写“不适用”。

已知延期：Notion 行内公式可能粘贴为占位符；菜单栏图标可能不可见。使用普通窗口和已接受的 Markdown / Lark / Notion 入口；记录影响，不将延期项标为修复。

Personal MVP 仍不包含 App Store 发布、后端/账户/订阅、云历史、文档导入或本地 Marker 回退。Notion 适配为实验性剪贴板行为，不保证通用 Native Paste。离线预览使用捆绑资源。

结束时由使用者填写：是否连续完成 14 天、Golden Set 报告、重截/速度汇总、是否出现丢失/泄漏、是否愿意替代 Mathpix，以及是否允许进入 Public Product 阶段。此处不预先宣称通过。
